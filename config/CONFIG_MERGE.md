## ВЫВОД (новый)
- **Модель = пользовательский выбор.** НЕ хардкодить `polza/deepseek/...` как обязательную модель.
- Приоритет: явный `-m` / выбор в UI > переменная (`OPENCODE_MODEL`) > текущий дефолт opencode (что выбрано по умолчанию).
- Провайдеры arise/hiai не «воюют» за модель: их дефолты (monarch `claude-opus-4-5`) валидны только если пользователь так выбрал.
