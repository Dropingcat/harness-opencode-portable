Принимающий worktree — место разработки; канонический E:\opencode_harness_portable остаётся отдельной принимающей стороной с проверкой конфликтов.

Сохраняются роутер W5, наблюдатель режима B, сны и рефлексия, корзины, существующий TD CLI, фабрика, память и геймификация. Не включаются автоматическая промоция уроков, самостоятельный merge, native semantic execution или новый провайдер. Незакрытый guard-stage1 не сбрасывается и не объявляется принятым.

## A1: контракт первого модуля

**Goal:** исправить подтверждённую потерю TraceStore при reload и stale-writer overwrite без замены публичных моделей/формата.

**Scope in:** scripts/meta/trace_store.py; новый узкий scripts/meta/durable_json.py при необходимости; tests/coder/test_trace_store_durability.py; краткая документация ошибок/миграции. Использовать scripts/meta/daemon_safety.py FileLease, не вводить второй механизм PID-only locks.

**Scope out:** DamageBasket/соны/роутер/память/guard/native plugin; производственные state-файлы; глобальная конфигурация, зависимости, пользовательские данные, канонический deployment. Это последующие транши.

**Input:** текущий JSON entries/transitions/state_snapshots, совместимый исходный формат; отдельные экземпляры/процессы с явным storage_path.

**Output:** то же содержимое с сохранёнными идентификаторами/временем; атомарная read-modify-write транзакция под kernel-owned lock; структурированное исключение при corruption/unsupported shape/lock timeout. Чтение ошибки не перезаписывает повреждённый файл пустым состоянием.

**Acceptance:** unittest round-trip entries/transitions/snapshots; две устаревшие копии и два конкурентных процесса сохраняют оба события; failure injection перед replace сохраняет прежние байты; блокировка имеет deadline, освобождается после исключения/завершения владельца; неизвестные некорректные данные не становятся пустым успехом; caller data и публичные сигнатуры не меняются без необходимости. Не заявлять общий exactly-once или replay correctness без отдельного теста соответствующей функции.

**Guard/test:** только синтетические значения и tempfile с явными путями; никакого запуска production MetaCore, сна, daemon, записи HP, чтения OAuth или реальных логов. Старый JSON не мигрируется автоматически на месте.

**Sunset:** временные пробы удаляются при завершении тестов; общий primitive остаётся только как владелец транзакций TraceStore и будущего Basket, без универсального framework. Возврат к обходу прямой write_text не допускается как fallback.

### A1: первая ограниченная переработка

Специализированный reviewer воспроизвёл обход общей блокировки через file symlink: sidecar lock создаётся для alias, а replace разрушает ссылку. Это in-scope дефект идентичности пути. Исправление должно либо разрешать все принятые обращения к одному target/lock, либо явно отклонять неподдерживаемые file aliases до записи; hard-link поведение также нельзя выдавать за поддержанное без проверки.

Worker и tester отдельно эскалировали очистку локально открытого handle при неожиданной не-OSError в FileLease.acquire. Для этого первого rework явно разрешена минимальная правка только метода acquire в scripts/meta/daemon_safety.py плюс изолированный regression-тест. execute_verified, DaemonLease, heartbeat и поведение запуска демонов остаются вне scope. Это согласованное расширение зависимости, не отдельное разрешение активировать meta-контур.
