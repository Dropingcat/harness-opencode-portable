## 1. ЦЕЛЬ
Гасить энтропию фабрики детерминированно: сторонний смотритель (аудитор) наблюдает,
бросает находки в корзину, обработчик за «монетки» превращает их в TD/исправления.
Гейм-система (уровни/монетки/ачивки) создаёт стимулы и тыкает в косяки исполнения
(не использовал инструмент, поленился запустить ресерчера, поискал но не применил).

## 3. ПОЛУКОЛЬЦО (смотритель → корзина → обновитель → TD → исправление → смотритель)
- Смотритель (ExternalAuditorV2, режим B): ТОЛЬКО наблюдает, бросает находки в корзину, НЕ правит.
- Корзина: `.runs/entropy/bucket.json` (изоляция, severity→урон, как damage_basket).
- Обновитель (td_updater): обрабатывает находки «за монетки» → PROBLEMS_REGISTER (05).
- Цикл: находка → bucket → обновитель → TD → контракт/код-фикс → смотритель верифицирует закрытие.

## 5. ГЕЙМ-СИСТЕМА (монетки, уровни, ачивки)
- Монетки (эскроу-экономика): за что (нашёл реальный косяк → +, обработал TD → +, использовал инструмент правильно → +, замкнул цикл → +); штраф (рецидив косяка → −, само-судейство → −).
- Где: `.runs/entropy/scoreboard.json` + `ledger.json` (аудит начислений) + `recidivism.json` (рецидивы косяков).
- Уровни: по formula character_sheet (XP за закрытие TD, за детерминизм, за качество).
- Ачивки: «Разобрался и применил» (E3-антитеза), «Замкнул цикл», «Первый сон» и др.
- Гейм-скилы = реальные скилы фабрики (adversarial-critic-checklist и пр.): использование → монетки.
- Связь с W10: рецидивы косяка → урок в самообучение (+ штраф).

## 6. ДЕТЕРМИНИЗМ (код решает, не LLM)
Правило: начисления монеток/штрафов — ТОЛЬКО кодом (парсер артефактов: verified_by_commands есть? E-детектор сработал? TD закрыт?).
Примеры (C1-C19): событие → код-проверка → +N/−N. Ноль «LLM судит LLM». Анти-шум через precision (детектор срабатывает только при 100% подтверждении).
