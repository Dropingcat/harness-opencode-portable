## Главные находки (по канону)

1. **Хуки (гл.13)** — критический пробел: нет хука на изменение сессии (git-session-sync), нет восстановления после сжатия. Канон: «хук отрабатывает всегда, контекст не жрёт». → M5.
2. **Эвалы/разброс (гл.20,23)** — цикл сна не прогоняется N раз; один зелёный прогон = лотерея. → M8 Monte-Carlo.
3. **Дом (гл.29)** — демон без проверки живости и с пороговым триггером (а не «нарушение ожидания»). → M9, M11.
4. **Baseline/чекпоинты (гл.26)** — нет суб-трекеров веток сна. → M7.
5. **Строка-лекарство (гл.27)** — «работаем по документации и фактам» отсутствует в контрактах. → добавить.
6. **Заборы (гл.34)** — нет снапшота перед крупным изменением (baseline). → M6.
7. **Скрипты (TD-127)** — ~110 ad-hoc скриптов разбросаны; часть канонизирована, часть уникальна → архив в scripts/legacy.

## План исправлений (приоритет)

- **M5** git_session_sync.py (хук: цепляет текстовые изменения сессии → коммит → аудитор на несоответствие).
- **M6** sleep_git.py (суб-ветка от baseline до critical damage, разбор fix/*, merge, возврат к baseline, снапшот).
- **M7** baseline_tracker.py (глобальный трекер + суб-трекеры веток, baseline-снапшоты, чекпоинты).
- **M8** monte_carlo_sleep.py (N прогонов, вариация hp/threshold, доля успеха, разброс).
- **M9** hp_regulator.py (hp → interval/глубина аудита; триггер «нарушение ожидания»).
- **M10** perfectionist + skill_master в цикл сна (изоляция, схлопывание после полировки).
- **M11** интеграция M5-M10 в meta_daemon + потолок расхода + проверка живости.
- **Кросс-фиксы**: строка «по документации» в шаблоны; вычистить «всегда» из shared; эвал-набор; ревью «на входе» + схлопывание.
