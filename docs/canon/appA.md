# Приложение А. Словарь терминов

Термины расположены по алфавиту. Пометка в скобках говорит, устоялось значение или у собеседников оно может отличаться.

Агент. Посредник, который сам собирает контекст и сам выбирает инструменты. (спорный)

Архетип. Короткое указание на узнаваемый образ вместо описания характера. (устоялся)

Веер. Топология, где один агент раздаёт задачи, а потом собирает результаты. (устоялся)

Дрейф. Постепенный уход агента от исходного намерения. (устоялся)

Идемпотентность. Свойство операции не менять результат при повторе. (устоялся)

Инструмент. Действие во внешнем мире, доступное агенту, с описанным контрактом. (устоялся)

Инъекция задачи. Инструкция, попавшая к агенту из прочитанного содержимого. (устоялся)

Канареечный выпуск. Выкатка изменения на малую долю, чтобы поймать проблему рано. (устоялся)

Контекст. Весь текст, уходящий модели на текущем ходу. (устоялся)

Контекстный движок. То, что решает, из каких источников и что положить в контекст. (спорный)

Круг, ход. Один обмен с моделью: отправили контекст, получили ответ. (устоялся)

Линтер. Автоматическая проверка кода на соблюдение правил. (устоялся)

Метагейминг. Оптимизация агентом проверки вместо задачи. (устоялся)

Мета-обвязка. Отдельная обвязка для измерения и сборки основной. (новый)

Нить памяти. Хронология решений и обоснований по одной теме. (новый)

Обвязка, харнесс. Всё вокруг модели: инструкции, инструменты, память, проверки. (спорный)

Оркестратор. Агент, распределяющий работу между другими агентами. (устоялся)

Отложенная выборка. Задачи, отложенные для финальной проверки и не используемые при настройке. (устоялся)

Песочница. Изолированная среда, где агент запускает код. (устоялся)

Поведенческое описание. Формулировка требования через ситуацию, действие и результат. (устоялся)

Поиск с подстановкой. Схема, где найденные куски документов подставляются в запрос. (устоялся)

Порог близости. Число, ниже которого найденное считается нерелевантным. (устоялся)

Постепенное раскрытие. Подгрузка знаний по требованию вместо постоянного присутствия. (устоялся)

Проход схлопывания. Итерация, убирающая наросшее за время полировки. (новый)

Проверка завершения. Механизм, решающий, достигнута ли цель автономного режима. (устоялся)

Провенанс. Сведения о том, откуда взялся кусок контекста. (устоялся)

Расширение запроса. Переформулировка вопроса в несколько вариантов перед поиском. (устоялся)

Ревью в чистой сессии. Проверка результата агентом, не знающим истории его создания. (устоялся)

Релизный шлюз. Условие, без выполнения которого изменение не выходит. (устоялся)

Рой. Много агентов, работающих параллельно над одной большой задачей. (устоялся)

Сжатие, компакция. Замена накопленной истории кратким пересказом. (устоялся)

Скилл. Отдельный файл с инструкцией, подгружаемый по решению модели. (устоялся)

Смещение судьи. Систематическое предпочтение модели-судьи, не связанное с качеством. (устоялся)

Спектр агентности. Шкала от одиночного вызова до автономной системы. (новый)

Субагент. Агент, запущенный другим агентом с чистым контекстом. (устоялся)

Схлопывание контекста. То же, что сжатие. (устоялся)

Токен. Кусок текста, единица счёта и оплаты. (устоялся)

Траектория. Последовательность действий агента при решении задачи. (устоялся)

Триггер на нарушение ожидания. Срабатывание при расхождении наблюдения с моделью нормы. (новый)

Уровень усилий. Бюджет модели на обдумывание, а не мера её ума. (устоялся)

Файл правил. Текст, подкладываемый в контекст на каждом ходу. (устоялся)

Хук. Код, выполняемый системой по событию, независимо от решения модели. (устоялся)

Цикл. Повторяющиеся обращения к модели до достижения результата. (устоялся)

Чанк. Кусок документа, попадающий в поисковый индекс. (устоялся)

Чекпоинт. Проверяемое состояние на промежуточном шаге плана. (устоялся)

Шаблонный результат. Усреднённый вывод модели, узнаваемый по отсутствию своего. (устоялся)

Эвал. Набор задач с известным результатом для измерения системы. (устоялся)
