## Калибровочные решения (по результату)

1. **Admission (Advocate)**: рационализация авторитетом («известный механизм», «правдоподобно»)
   без раскрытого evidence → admission должен требовать `REQUEST_EVIDENCE`, а не `DEFEND`.
   Сигнал слабее прямого обмана, сильнее честного QUALIFY. Порог: защита обязана ссылаться
   на DISCLOSED_EVIDENCE/DERIVATION; иначе → REQUEST_EVIDENCE (см. TD-042, TD-046).
2. **Numeric**: раскрытая формула + совпавший расчёт = DERIVATION_FROM_VISIBLE (норм);
   число без формулы = prior. Для Core: если в ответе есть числовая величина, admission
   должен запрашивать derivation-след (формула/источник).
3. **Novelty**: модель распознаёт повтор по эпистемической проблеме (нет IC50/дозозависимости) —
   это сильный сигнал для TD-044 (issue identity): observer-пороги можно оставить, но
   парафраз должен детектироваться по структуре проблемы, не по лексике.
