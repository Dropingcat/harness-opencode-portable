# Superpowers: общий цикл планирования для OpenCode V2

## Поведение

Глобальный адаптер подключает неизменённый Superpowers 7.0.1 и короткий
рабочий цикл `PLAN → ACT → CHECK`, с `WAIT_CHILDREN`, `DONE`, `BLOCKED`.

- Основные сессии получают штатный bootstrap Superpowers и общий цикл.
- Дочерние сессии получают общий цикл и доступ к навыкам, но не начинают
  заново штатный процесс обсуждения и согласования всего проекта.
- Цикл добавляется в исходящий контекст до запроса модели, включая
  продолжение после инструмента. Это не поиск ключевых слов в промпте.
- После компакции цикл снова доступен в следующем рабочем контексте.
- Заголовки, вспомогательная генерация и сам запрос компакции не запускают
  планирование: регистрируется только `session.hook("context")`.
- Уже существующие навыки с совпадающими ID не заменяются. Разрешения,
  роли, модели, инструменты, итоговые JSON-контракты не переписываются.

При временной невозможности проверить идентичность сессии полный
контроллерный bootstrap откладывается до следующего запроса. Короткий
цикл остаётся доступен. Неуспешная классификация не кешируется; кеш
успешных идентичностей ограничен 256 записями.

Дочерняя сессия отсекается по проверенной идентичности непосредственно
в текущем вызове, до передачи управления upstream. Поэтому вытеснение
общего кеша между двумя асинхронными запросами не превращает ребёнка
в контроллер. Это покрыто тестом на 257 одновременных дочерних контекстов.

Это слой инструкций для самоконтроля, НЕ внешний детектор затруднения,
не принудительно исполняемый автомат состояний и не долговременная
память задач. Наличие инструкции не доказывает её соблюдение моделью.
Семантическое поведение всех ролей требует отдельной оценки на задачах.

## Размещение

- Исходный адаптер: `src/index.js` в этом пакете.
- Глобальная точка входа:
  `C:\Users\Arhys\.config\opencode\plugins\superpowers-planning\index.js`.
- Зафиксированный upstream:
  `C:\Users\Arhys\.config\opencode\external\superpowers-v7.0.1`.
- Происхождение и контрольные суммы:
  `C:\Users\Arhys\.config\opencode\external\superpowers-installation.json`.

Глобальная точка входа ссылается на исходник на диске E:. При переносе
harness нужно обновить эту ссылку. Файлы существующих агентов и
`opencode.jsonc` не меняются. Обновление upstream не автоматическое.

## Проверки

Используется встроенный `node:test`, без новых npm-зависимостей.

```powershell
$env:SUPERPOWERS_ROOT = 'C:\Users\Arhys\.config\opencode\external\superpowers-v7.0.1'
npm test
npm run check
```

Контрактные тесты используют настоящий модуль Superpowers 7.0.1, но
управляемую модель OpenCode-host: корневая/дочерняя сессия, сохранение
навыков и ограничений, дедупликация, свежий контекст, компакция,
недоступная/ошибочная идентичность сессии, восстановление и очистка.

До внедрения сохранена контрольная запись путей навыков и хеша
определений агентов: `C:\Temp\opencode\superpowers-install-v7.0.1\before.json`.
Нативная загрузка и регистрация должны проверяться отдельно через API:

```text
GET /api/plugin?location[directory]=F:\1
GET /api/skill?location[directory]=F:\1
```

Успешные контрактные тесты не равны запуску всех агентов на реальных
задачах. Конфликты с существующими навыками проверяются сохранением их
путей; определения агентов — сравнением хеша до и после.

Машиночитаемые результаты и контрольные суммы: `VERIFICATION.json`.

## Отключение

Для отключения только этого дополнения можно добавить
`-harness.superpowers.planning` в конец массива `plugins` соответствующей
конфигурации OpenCode V2. Не удалять чужие записи и не менять разрешения.
Другой вариант — перенести только каталог `plugins\superpowers-planning`
за пределы автоматически обнаруживаемого каталога plugins.

OpenCode наблюдает изменения конфигурации, но для изменений во внешнем
исходнике может потребоваться перезагрузка. Общий сервис автоматически
не перезапускается: это могло бы прервать параллельные сессии.
