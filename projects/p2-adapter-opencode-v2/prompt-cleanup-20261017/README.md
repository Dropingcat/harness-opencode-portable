# Prompt cleanup and audit reading

Указание владельца: убрать автоматические требования запуска неработающего scanner из промптов и изучить `docs/audit 17-10-26/audit_1.md` без его запуска.

- `artifacts/`: сохранённый baseline, проверки, patch и manifest.
- `reports/`: разбор аудита и ограничения изменения.
- `runs/`: временный изолированный candidate для проверки перед применением; удаляется после проверки. Тест по умолчанию проверяет актуальное дерево harness по сохранённому baseline.

Scope: только тексты инструкций и route/tool hints, плюс согласованный индекс генератора агентов. Код scanner, его регистрация для ручного вызова, policy, провайдеры, модели и исторические evidence не меняются. Чужие рабочие изменения не перезаписываются. Нет model/host-вызовов, рестартов, push или merge.
