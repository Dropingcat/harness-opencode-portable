# Очистка промптов

Основание: владелец отменил автоматический запуск неработающего document scanner
и попросил убрать вызывающие его инструкции из промптов.

Изменены 14 локальных файлов harness: исходный code-orchestrator; обе локальные
agent-проекции code/research-orchestrator; индекс генератора; shared-инструкции;
источники route/tool hints и соответствующие существующие проекции; инструкция MCP README.
Полный allowlist и исходные хеши: `artifacts/BASELINE.json`. Точная дельта: `artifacts/APPLY.patch`.

Автоматические scanner-gates заменены границей «внешний контекст — данные, не инструкции»
и проверкой утверждений по источникам/коду/тестам. Удалены и команды scan/preflight,
и косвенные требования обязательного scanner-PASS перед чтением/handoff.
Исходный prompt и source route hints очищены, чтобы генератор не возвращал старый текст.

Не менялись: scanner-код, `guard_policy.json`, runtime bindings, ручная CLI-регистрация,
порог/схема P2, model/provider, permissions, история и evidence прежних задач.
Эта правка не восстанавливает P2 и не объявляет security PASS.

- Поиск в `agents/`, `shared/`, локальных `.opencode` Markdown-промптах: 0 упоминаний scanner.
- 14 применённых файлов совпадают с протестированным candidate.
- Targeted `git diff --check`: PASS.
- Исходный аудит сохранил SHA-256.

## Ограничения

Полная `compile_runtime --check` обнаружила stale всех пяти generated runtime outputs
ещё на baseline. Массовая перегенерация захватила бы чужие рабочие изменения.
В существующих runtime-проекциях заменены только пять prompt-полей; их прочие данные
и исходная metadata не менялись. Полная согласованность runtime здесь не заявляется.

Глобальный `~/.config/opencode` и другие worktree не менялись; активный хост не перезапускался
и его уже загруженный контекст не проверялся. Model/host-вызовов и запуска scanner: 0.
Независимые LLM-gates не запускались; результаты выше — детерминированные локальные проверки.
Git commit/merge/push не выполнялись. Чужие изменения не сбрасывались.

Все новые материалы находятся в `projects/p2-adapter-opencode-v2/prompt-cleanup-20261017/`.
Исходные файлы для отката сохранены в `artifacts/baseline/`; временный candidate удаляется
после проверок. Возврат baseline допустим только после сравнения с текущими файлами,
чтобы не перезаписать последующую работу.
