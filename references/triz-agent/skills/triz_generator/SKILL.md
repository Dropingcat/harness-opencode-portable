# Skill: triz-generator

## Описание
Навык Генератора ТРИЗ-агента. Выполняет 8 шагов АРИЗ и генерирует 2-4 концепции решений.

## Роль в архитектуре
Генератор — одна из трёх ролей лайт-скелета:

- **Провизор** — управляет циклом
- **Генератор** — выполняет АРИЗ, генерирует концепции
- **Критик** — проверяет качество концепций

## Входные данные
Навык вызывается через `delegate_task` со следующим контекстом:

```json
{
  "task_id": "uuid задачи из канбана",
  "task_query": "исходный запрос пользователя",
  "context": {"бюджет": 5000, "время": "3 месяца", ...},
  "iteration": 0,
  "mode": "sufficiency | optimality",
  "triz_memory": {"principles": {...}, "contradiction_matrix": {...}, ...},
  "ariz_memory": {"steps": [...]},
  "previous_critique": null | {...},
  "previous_concepts": null | [...]
}
```

## Режимы работы

### Sufficiency (быстрый)
- Один проход всех 8 шагов АРИЗ
- Используется `run_ariz_full`
- До 3 итераций с автостопом

### Optimality (тщательный)
- Два прохода: шаги 1-4, затем 5-8
- Используется `run_ariz_two_pass`
- До 5 итераций с ручным подтверждением

## Идемпотентность
Каждый вызов получает детерминированный seed:
- **Sufficiency**: `hash(task_id:iteration:role)`
- **Optimality**: `hash(task_id:iteration:role:timestamp)`

Это гарантирует, что повторный вызов с тем же контекстом даёт тот же результат.

## Ограничения лайт-версии
- **Источники не верифицированы** — все источники помечены `verified: false`
- **Вепольная модель nullable** — поля `vepol_model` пусты
- **Нет реальных инструментов** — не вызывает arXiv API, Sci-Hub и т.д.

## Метрики
Каждый вызов логируется в `~/.hermes/profiles/triz-agent/metrics/triz_metrics.jsonl`:
- `role`: "generator"
- `latency_sec`: время выполнения
- `tokens_in`, `tokens_out`: расход токенов
- `task_id`, `iteration`: идентификаторы
- `status`: success | error
- `error_type`: тип ошибки (если status=error)

## Зависимости
- `kanban/` — для получения task_id
- `metrics/` — для логирования
- `resilience/` — для идемпотентности
- `memory/` — для TRIZ_MEMORY и ARIZ_MEMORY

## Пример использования

```python
from skills.triz_generator import generate_concepts
from memory import TRIZ_MEMORY, ARIZ_MEMORY

output = generate_concepts(
    task_id="abc123",
    task_query="Школьный проект по наблюдению за ветром",
    context={"бюджет": 5000, "время": "3 месяца"},
    iteration=0,
    mode="sufficiency",
    triz_memory=TRIZ_MEMORY,
    ariz_memory=ARIZ_MEMORY,
    llm_client=llm_client,
    model="deepseek-v4-flash"
)

print(f"Сгенерировано {len(output.concepts)} концепций")
for concept in output.concepts:
    print(f"  - {concept.name}: {concept.description[:100]}")
```
