# 31. Unified Extraction Pipeline — детерминированный + LLM + QC → графы

> Статус: **v0.1** (05.09.2026). Прогон: 40 абзацев автореферата (Блинова Е.В.).

---

## 1. Архитектура

```
Текст (абзац/параграф)
  │
  ├─ C1-C7 детерминированные (структура, C5 числа, C8 термины, филология)
  │
  ├─ [не-таблица] LLM (gemma-4-26b-a4b-it, temp=0):
  │     • claims (научные утверждения + claim_kind/role/strength + span)
  │     • scope (material/environment/condition/method + span)
  │     • objects (странные формы + span)
  │
  ├─ QC (claim_qa): span_grounding КАЖДОГО извлечённого (в тексте или отброс)
  │     + детерминированная типизация (role/kind)
  │
  ├─ DEDUP: LLM-claims приоритетнее детерминированных (span-overlap)
  │
  └─ graph_builder → 12 графов (только GROUNDED артефакты)
```

Принцип: **LLM ПРЕДЛАГАЕТ, код ПРИНИМАЕТ/ОТКЛОНЯЕТ** (span grounding).

## 2. Cкрин — детектор таблиц

Абзац-таблица (≥15 чисел, плотные хим.обозначения) направляется мимо LLM
(иначе каждая строка становится «claim»). Но числа/стали в таблице извлекаются
детерминированно (C5, стали).

```python
def _is_table_like(text):
    nums = len(re.findall(r"\d+[.,]?\d*", text))
    chem = len(re.findall(r"\b\d{1,3}[А-ЯЁA-Z]{1,3}\d*", text))
    words = len(re.findall(r"[а-яёa-zA-Z]+", text))
    return nums >= 15 and words > 5 and (nums / max(1, words)) > 0.5
```

## 3. QA (claim_qa) — контроль качества

- **span_grounded/span_locate**: claim обязан быть дословным фрагментом текста
  (нормализованно; пересказ → none → отброс). АНТИ-ГАЛЛЮЦИНАЦИЯ.
- **Антихрупкость**: типографика (диапазоны «0,1–0,4», единицы «мг/м²ч» == «мг/м2ч»,
  оС == °С), но числа НЕ стираются («400» ≠ «0,1-0,4»).
- **Короткие claims** (<5 слов): только exact substring (не fuzzy).
- **classify_claim**: role/kind детерминированно (не на слово LLM).

## 5. Подтверждённые инварианты

1. LLM не галлюцинирует на пустом/прозе без фактов: вернул `[]`.
2. Пересказ (не цитата) → span grounding → отброс.
3. Таблица → детектор → claims=0 (не 14), но объекты (стали) извлечены.
4. C5-NUMBER после фикса: `0,1–0,4 мг/м2ч`, `г/м2`, `МДж/м2`, `corrosion_rate` — точны.
5. DEDUP span-overlap удалил дубли (P1: 4 → 2 claims).

## 6. Известные лимиты (честно)

1. **Таблицы**: внутренние числа не собраны как Quantity (нужен C2-tables).
2. **Recall claims**: 13 «0-claim» абзацев могут содержать факты без сильных глаголов
   (эвристика ориентирована на глагольные предикаты).
3. **C5 для таблиц**: составные колонки не обрабатываются.
4. **Scope** извлекается, но НЕ привязан к конкретному claim (G5 scope-ребро не создано).

## 7. Модули (src_skeleton/extractor/)

- `c1_c2_structure.py` — PDF → canonical (структура)
- `c5_number.py` — числа+единицы (Quantity)
- `extraction_engine.py` — детерминированные объекты/claims/хвост
- `philologcal_layer.py` — морфология/фигуры/хрия/связки
- `claim_qa.py` — span grounding + типизация (QC)
- `llm_extractor.py` — gemma (claims/scope/objects)
- `graph_builder.py` — артефакты → 12 графов
- `unified.py` — сборка всё (дет+LLM+QC+dedup+графы)
