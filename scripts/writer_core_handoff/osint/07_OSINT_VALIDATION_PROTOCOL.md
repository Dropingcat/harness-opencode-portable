# OSINT 07. Validation Protocol

Benchmarks must separate train/test by document, time, topic and where possible journal/template/coauthor to prevent leakage.

Evaluate:
- verification ROC/DET/EER where appropriate;
- calibration error;
- open-set rejection/OOD;
- feature ablation;
- robustness to paraphrase/translation/editing;
- minimum sample length;
- cross-domain generalization;
- false accusation rate.

Human-readable forensic report must distinguish measured evidence, inference and unresolved alternatives.
