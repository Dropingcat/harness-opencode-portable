# AI Slop Avoidance (slop-audit)

Детерминированный чек-лист для качества публицистической прозы. Запускается **перед** передачей черновика пользователю/читателю. Это гейт, а не реклама: если чек-лист не пройден — правим, не «оставляем как есть».

## Как применять

1. Перечитай текст от начала до конца **один проход** (не по кусочкам).
2. Выполни каждый пункт ниже; отвечай ДА/НЕТ по каждому.
3. Если хотя бы один пункт = ДА (нарушение) — отметь и исправь, затем проверь заново.
4. Верни кратко: «slop-audit: N нарушений, исправлено/осталось».

## Чек-лист

### A. Структура (generic AI-style)
- [ ] A1. Открытие с клише («В современном мире…», «В эпоху…», «Любопытно, что…»)? 
- [ ] A2. Использование «как мы видим», «стоит отметить», «важно подчеркнуть» без пользы?
- [ ] A3. Выводы ради «закругления», а не ответа на вопрос/заострения?
- [ ] A4. Секции одинаковой формы «списка» без логики аргумента?

### B. Контент (invented / diluted)
- [ ] B1. Факты без источника или без вывода «inference»?
- [ ] B2. Особые числа, цитаты, имена, даты — есть ли у каждого источник?
- [ ] B3. Сглажен ли конфликт источников в ложный консенсус?
- [ ] B4. Water что-то непроверенное подано как факт?

### C. Язык (generic / padded)
- [ ] C1. Пустые атрибуты типа «важнейший», «ключевой», «революционный» без выписки доказательства?
- [ ] C2. Длинноты, которые можно сократить без потери смысла (пассив-замусор)?
- [ ] C3. Повтор одного и того же разными словами в разных секциях?
- [ ] C4. Членение «кстати», «между прочим», «хотя, эм» не по делу?

## Правила исправления

- **Конкретность:** каждое общее утверждение → конкретный механизм, имя, дата, число где есть источник.
- **Атрибуция:** анализ приписан именованным людям/институтам/публикациям; без «некие эксперты».
- **Ссылки:** каждый значимый факт имеет URL/doi или явный caveat. Убирать tracking-параметры из URL.
- **Не раздувать:** если источника хватает на короткий текст — писать короткий. Коротко — не плохо.
- **Завершение:** конец отвечает на центральный вопрос, заостряет вывод или называет что осталось неопределённым. Не «в заключение можно сказать…».

## Интеграция

- `article-writer`: обязательный шаг перед handoff (см. `article-writing-process.md`).
- `writing-orchestrator`: финальная проверка статьи перед выдачей.
- Выходной формат: короткая строка «slop-audit: N нарушений → исправлено/осталось» в handoff-ноте.
