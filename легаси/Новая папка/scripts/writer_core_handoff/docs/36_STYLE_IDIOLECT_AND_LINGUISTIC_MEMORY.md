# Style, Idiolect and Linguistic Memory

Style profile is a distribution over linguistic choices, not a bag of preferred phrases.

## Feature groups
- lexical/sense preferences;
- collocations and valency;
- sentence topology and dependency depth;
- clause ordering;
- nominalization/passive preferences;
- theme-rheme progression;
- connective/metadiscourse distribution;
- hedge/booster behavior;
- paragraph topology;
- rhetorical/argument patterns.

## Conditioning variables
Profiles MUST be conditioned where possible by language, genre, domain, time, editor/journal/template and coauthor context.

## Memory output
Tier-1 receives only compact `style_guidance`. Tier-2 MAY receive distributions and competing hypotheses. Memory has no direct write authority to document or epistemic graphs.
