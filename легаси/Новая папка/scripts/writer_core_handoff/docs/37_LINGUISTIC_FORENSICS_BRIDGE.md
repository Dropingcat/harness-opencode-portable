# Linguistic ↔ Forensics Bridge

Writer quality and authorship forensics may share feature extraction but MUST remain separate consumers.

Shared features include lexical choice, syntactic topology, discourse patterns, metadiscourse, hedging, collocations and rhetorical habits.

Forensics additionally models confounders: topic, genre, journal, institution, editor, coauthor, language, time, software and LLM assistance.

A Writer style profile MUST NOT be used to optimize specifically against the forensic detector. Attribution remains open-world and calibrated; linguistic similarity is evidence for a hypothesis, not identity proof.
