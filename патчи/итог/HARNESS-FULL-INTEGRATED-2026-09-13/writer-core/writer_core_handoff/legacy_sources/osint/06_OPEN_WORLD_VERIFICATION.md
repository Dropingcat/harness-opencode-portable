# OSINT 06. Open-world Verification

Closed-world `choose one of N authors` is insufficient.

Verdicts:
- MATCH
- LIKELY_MATCH
- INCONCLUSIVE
- LIKELY_DIFFERENT
- DIFFERENT
- UNKNOWN_AUTHOR
- OUT_OF_DISTRIBUTION

Verdict requires candidate corpus adequacy, calibration, per-feature evidence, confounders, alternative explanations and sample-length adequacy.

No forced nearest-author assignment.
